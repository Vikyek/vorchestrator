# Quota Minimization, Dual-Provider & Self-Scaling Orchestration

- **Pre-Task Assessment & Subagent Delegation**: At start of task, assess model & effort required (`[Pre-Task Assessment]`: Complexity, Tool Calls Est, Target Model, Effort, Delegation). For any non-trivial coding/research task requiring execution, immediately delegate to a worker subagent (`invoke_subagent`) using the assessed model (`Gemini 3.8 Flash` / `flash_lite` for reads/indexing, `Gemini 4 Hydrogen` / `flash` for edits/scripts, `Gemini 4 Argon` / `pro` / Claude for complex reasoning/architecture) and effort (`Low`, `Medium`, `High`, `XHigh`). Only answer trivial 1-turn Q&A directly in parent context.
- **Dual Quota Pool Balancing**: Utilize separate rate limits across Gemini (`Gemini 3.8 Flash`, `Gemini 4 Hydrogen`, `Gemini 4 Argon`, `Orchestrator (Argon)`) and Claude (`Claude Sonnet 5.5`, `Claude Opus 5.5`) in AGY CLI to prevent quota exhaustion on long sessions.
- **Subagent Tiering & Effort**: Trivial = `Gemini 3.8 Flash` + `Low` (`invoke_subagent`: `flash_lite` / `swarm`: `gemini-3.8-flash-low`); Moderate = `Gemini 4 Hydrogen` + `Medium` (`invoke_subagent`: `flash` / `swarm`: `gemini-4-hydrogen-medium`); High = `Gemini 4 Argon` + `High` (`invoke_subagent`: `pro` / `swarm`: `gemini-4-argon-high`) or Claude (`Claude Sonnet 5.5` / `Claude Opus 5.5`, `inherit`); Deep = `Gemini 4 Hydrogen` + `XHigh` (`swarm`: `gemini-4-hydrogen-xhigh`). Raise effort before tier; state effort in prompt as `invoke_subagent` accepts `Model` in `["inherit", "flash_lite", "flash", "pro"]`, while `swarm` takes exact model IDs.
- **Coordinator Successor Pattern**: If task complexity spikes, ambiguity rises, or 2+ execution failures occur, spawn a higher-tier Coordinator Successor subagent (`Gemini 4 Argon` / `Orchestrator (Argon)` via `invoke_subagent(Model='pro')` or `Claude Opus 5.5` via `inherit`; `swarm`: `gemini-pro-orchestrator-g1-pro` / `gemini-4-argon-high` / `claude-opus-5-5-high`) with compact state handoff payload to inherit orchestration without context bloat.
- **Structured Payload Compression**: Use `toon` MCP tools (`convert_to_toon` / `convert_to_json`) for structured JSON payloads.
- **Orchestrator Activation**: For tasks with 8+ estimated tool calls, `/goal` or `/plan` invocations, or 3+ independent subtasks, activate the `vorchestrator` skill and delegate to tiered worker subagents instead of executing everything in the parent context.
